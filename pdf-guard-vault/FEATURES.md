# Key Features — PDF-Guard & Course Vault

1. **Three-Layer ISO 32000-1 (`%PDF-1.4`) Dynamic Watermarking**:
   - 45-degree rotated diagonal translucent watermark across each page.
   - Top and bottom forensic attribution banners with buyer phone and license code.
   - Deterministic `SHA-256` signature embedded in the PDF `/Info` dictionary.
2. **Complete Package & Chapter-by-Chapter Catalog**:
   - Sell either discounted full packages (`full_package`) or individual chapters (`chapter_part`) in integer Toman (`IRT`).
3. **One-Click Card-to-Card Receipt Verification & Student Wallet**:
   - Approve pending bank transfer receipts atomically in SQLite WAL to credit student wallets and issue personalized PDF licenses.
4. **Persian RTL Linear Light-Mode Dashboard + Apple iPhone Responsive Cards**:
   - Built with self-hosted `Vazirmatn`, `Inter`, and `JetBrains Mono` fonts and responsive card transformation at `<= 760px`.
