# PDF-Guard & Course Vault v1.0.0

Dynamic three-layer PDF watermarking engine, hierarchical educational course store (`full_package` and `chapter_part`), student wallet ledger, and one-click card-to-card receipt verification platform.

## Quick Start

```bash
pip install -r requirements.txt
python main.py --host 0.0.0.0 --port 8092
```

On Windows, double-click `run-windows.bat` or `start_vault.bat`.
