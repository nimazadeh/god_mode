# Triage Labels

Canonical triage roles used across `.scratch/<product>/issues/*.md` and GitHub issues.

## Category Roles

- `bug`: Something is broken or behaves contrary to the specification.
- `enhancement`: New feature, architectural deepening, or performance improvement.

## State Roles

- `needs-triage`: Maintainer needs to evaluate and verify the claim.
- `needs-info`: Waiting on the user or reporter for clarification.
- `ready-for-agent`: Fully specified tracer-bullet slice ready for autonomous implementation.
- `ready-for-human`: Requires human action, credentials, or manual confirmation.
- `wontfix`: Out of scope or already implemented.
